# Archive

This directory contains the original research scripts written before the `qdot` package existed. They are kept for historical reference only, and reflect the state of the codebase before Claude Code was unleashed on it.

These scripts are not runnable without modification — they have hardcoded paths to `/home/will/Documents/...` and depend on local data files that are not in this repository. The `qdot` package supersedes all of them.
